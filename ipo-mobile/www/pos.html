Pilih foto atau screenshot QRIS — kolom di bawah terisi otomatis. Foto diproses di perangkat, tidak diunggah ke mana pun.

Tempel string QRIS statis warung (bisa dibaca dari QR cetak di meja/kasir). Setelah disimpan, kasir bisa menampilkan QRIS dinamis bernominal sesuai total transaksi — dibuat offline di perangkat, tanpa server atau gateway.

Pencetakan

Printer Bluetooth 58 mm

Belum diuji cetak.

1) Nyalakan printer dan pasangkan dari Pengaturan Bluetooth di HP (kode 0000 atau 1234). 2) Tekan "Muat ulang daftar" lalu pilih printer di atas. 3) Tekan "Test cetak" untuk memastikan.

Struk

Tulisan di struk

Muncul di bagian bawah setiap struk. Tiap baris = ganti baris. Kosongkan untuk memakai tulisan bawaan.

Ditampilkan sebagai alasan awal saat menolak pesanan. Jika dikosongkan, POS memakai “Mohon maaf stok habis”.

Data lokal

Cadangkan data

POS ini menyimpan data di perangkat ini. Aplikasi hanya menyimpan satu cadangan otomatis terbaru di perangkat (cadangan lama otomatis diganti) supaya penyimpanan tidak penuh. Salinan di server mengikuti sinkronisasi; tetap unduh file backup ke Google Drive minimal seminggu sekali.

—

Belum pernah download file backup. Data di perangkat ini hilang kalau app di-uninstall atau data browser dibersihkan.
